## 🔬 Research Background, Limitations & Academic Impact

### Previous Research & Methodological Roots
Prior terminal-based cryptography simulations and adversary emulation frameworks typically relied on static text scripts or rigid, turn-based user inputs that stalled execution loops. Traditional implementations suffered from several core limitations:

* **Manual Bottlenecks:** Operators were forced to manually step through every byte, key-segment, or firewall layer, breaking immersion and slowing execution.
* **High Latency & Rigid Architectures:** Heavy dependency on blocking I/O calls prevented smooth, real-time terminal animations and dynamic trace adjustment.
* **Monolithic Target Sets:** Hardcoded targets limited operational replayability and prevented customized adversary simulation.

### Research Gaps Addressed in v4.0
1. **Autonomous Execution Overhead:** Closing the gap between interactive terminal emulators and fully autonomous background-threaded decision engines.
2. **Dynamic Trace-Space Balancing:** Resolving the rigidity of fixed penalty models by introducing stochastic trace mitigation during quantum relay rotations.
3. **Cross-Environment Compatibility:** Overcoming ANSI terminal rendering discrepancies across lightweight mobile environments (**Termux**) and strict enterprise **PowerShell** terminals.

### Our Advancement & Impact
With **CIPHERGHOST v4.0**, we introduce:
* **Zero-Input Autonomous State Machines:** The keyspace automatically adjusts, bypasses firewall enclaves, and executes mitigation protocols without halting operations.
* **Optimized Rendering Pipelines:** Leveraging Python's `rich` library and customized byte-matrix generators to deliver fluid, high-frame-rate terminal animations without screen tearing.
* **Infinite Scenario Customization:** Integrated a 12-target global contract matrix alongside an interactive **Custom Contract Builder**.

## 🚀 Cross-Platform Installation & Execution Guide

### Prerequisites
* **Python `3.8` or higher** installed and added to your system `PATH`.
* A modern terminal emulator supporting **ANSI escape sequences** and **UTF-8 / Unicode box-drawing characters**.

---

### 🪟 1. Windows (Windows Terminal / PowerShell / CMD)

Open **PowerShell** as a regular user and execute the following commands:

```powershell
# 1. Clone the repository or navigate to your project directory
git clone [https://github.com/your-username/cipherghost.git](https://github.com/your-username/cipherghost.git)
cd cipherghost

# 2. Create an isolated Python virtual environment
python -m venv venv

# 3. Activate the virtual environment
.\venv\Scripts\Activate.ps1

# 4. Upgrade pip and install required TUI dependencies
python -m pip install --upgrade pip
pip install rich

# 5. Launch CIPHERGHOST v4.0
python cipherghost.py
```

> **💡 Windows Tip:** For optimal color accuracy and glyph rendering, run CIPHERGHOST inside **Windows Terminal** rather than legacy `conhost.exe`.
